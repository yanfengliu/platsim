## Simulation API

`simulation.gd` extends RefCounted with class_name MosslightSimulation. `new()` initializes a deterministic starting colony; `reset(seed_value: int = 42)` resets it. `step(dt: float)` accepts seconds, called at 10 Hz by the app. Simulation has no Node/UI dependency. Public data: `width: int = 48`, `height: int = 26`, `tiles: Array` of row Arrays with 0=open, 1=rock, 2=ore, 3=biomass, 4=water deposit; `colonists: Array[Dictionary]`; `buildings: Array[Dictionary]`; `jobs: Array[Dictionary]`; `resources: Dictionary` with food, water, ore, biomass, power; `rooms: Array[Dictionary]`; `elapsed: float`; `day: int`; `status: String` (playing/won/lost); `message: String`; `events: Array[String]`; `seed_value: int`; `objective_progress: float` (0..1).

Colonists contain id, name, pos: Vector2 (tile coordinates), health (0..100), hunger (0..100, higher means hungry), energy (0..100), task: String, alive: bool. Buildings contain id, kind: String, cell: Vector2i, active: bool, progress: float (0..1), reason: String. Jobs contain id, kind (dig/build), cell: Vector2i, building_kind: String, progress: float (0..1), assigned: int (-1 if unassigned). Rooms contain id, cells: Array[Vector2i], air: float (0..100). `room_at(cell: Vector2i) -> Dictionary` gives air information or empty dictionary. `cell_info(cell: Vector2i) -> String` gives helpful inspection and failure reasons.

`const CATALOG: Dictionary` maps ladder, bed, farm, airfern, lamp, generator, cistern, beacon to dictionaries with name, description, cost (dictionary). `queue_dig(cell: Vector2i) -> bool`; `queue_build(kind: String, cell: Vector2i) -> bool`; `cancel_job(cell: Vector2i) -> bool`; `can_build(kind: String, cell: Vector2i) -> String` returns empty when valid or actionable failure reason. No resource loss for rejected or canceled queued construction; reserve or charge consistently. Mouse drag may call queue_dig for each crossed tile; duplicates must be rejected without duplicate resource charges.

## Gameplay

Side-view terrain, navigable floors and ladders; colonists travel visibly before working. Jobs inaccessible to colonists remain queued with readable feedback. Initial chamber provides four beds and starter infrastructure/supplies sufficient for a learning period. Farms consume water and need light to produce food, airferns consume water and need light to produce air; generators consume biomass to produce power for lamps. A cistern collects a modest renewable water supply. Adjoining open air cells share a room, digging into a stale chamber mixes air by volume. Air consumption is local to colonists' rooms. Keep quantities finite and nonnegative. Eight build types as above. Win after maintaining a living colony and a powered beacon with sustainable food/air for a documented duration; loss when everyone dies, with a fresh retry. Pause and 1x/3x speed controls. No save/load format in this first milestone.
