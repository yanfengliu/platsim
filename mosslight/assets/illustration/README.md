# Mosslight illustration assets

`cavern-backdrop.webp` is an original image generated for Mosslight on 2026-11-07 with the built-in image generation tool. The selected artwork was inspected before conversion to WebP at quality 98, without changing its dimensions or composition. It is an opaque distant background; all traversable terrain, resources, light mechanics, buildings and colonists are drawn from simulation state in front of it. No commercial game assets or external runtime fetches are involved.

The full generated PNG is retained as ignored evidence under `output/imagegen/mosslight/cavern-backdrop-original.png`. The source is intentionally not committed because it exceeds the repository's binary size limit. The compressed runtime asset stays below 512 KiB.

Absolutely no flat horizontal foreground floor, no foreground ledges, no water pool or water surface, no buildings, no machines, no people or characters, no interface, no lettering, no symbols, no logos, no border, no watermark. ## Building props

`buildings-upper.webp` and `buildings-lower.webp` package a second original built-in image-generation result as two four-prop rows. Splitting the source at its row boundary preserves the full source resolution while keeping each binary under 512 KiB. WebP quality is 96; the alpha channel was verified byte-for-byte against the corresponding source row. No background removal, recoloring, shape edits or resampling were applied. The full PNG remains under ignored `output/imagegen/mosslight/buildings-atlas-original.png`.

The source is 1774 x 887 pixels. Upper row: ladder, bed, mushroom farm, airfern. Lower row: lamp, generator, cistern, beacon. `buildings-atlas.json` records exact texture-relative source rectangles, content bounds and ground pivots. Content bounds are measured using alpha >= 16 to exclude near-transparent generator fringe noise; this threshold is used only for metadata and does not modify the image alpha. Each source rectangle includes eight pixels of padding where the cell permits it. The renderer places props at authoritative simulation cells and may layer its own light, shadows and working animation.
